Tennis.Date

테니스 일정 관리 사이트 기획안

사이트 개요

사이트명

Tennis.Date

목적

테니스 일정을 달력으로 관리하고, 회원·게스트와 함께 참여 인원을 정리한다.

컬러 팔레트

#3fdf84 메인 컬러
#00a49d 서브
#2f4858 서브
#ffffff 화이트
#000000 블랙

사이트 기능

달력 보기

  • 월 / 주 / 일 단위 전환

회원 기능

  • 회원가입
  • 로그인
  • 가입한 회원 관리 페이지

일정 등록

  • 각 일자에 시간별 데이터 등록
  • 시작~종료 날짜 및 시간 선택 (datetime)

일정 데이터 항목

테니스장위치주차여부인원수레벨예약자금액메모

참여자 (회원)

인원 n명을 지정할 수 있으며, 참여자는 회원가입한 사용자의 데이터로 추가한다.

참여자 (게스트)

n명 중 '게스트'라는 이름의 데이터도 추가할 수 있다.

세부 메뉴 계획

메인페이지

Tennis.Date 로고로 만든 index페이지 추가

대메뉴

일정달력, 일정등록, 회원관리

세부메뉴

  • 일정달력 → 세부메뉴 없음
  • 일정등록 → 세부메뉴 없음
  • 회원관리 → 내정보, 전체관리

해당 사이트 우측 상단

한국시간기준 시계(YYMMdd hh:mm:ss 24h), 로그인버튼, 회원가입버튼
