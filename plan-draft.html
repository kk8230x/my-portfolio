Tennis.Date

테니스 일정 관리 사이트 기획안

사이트 개요

사이트명

Tennis.Date

목적

테니스 일정을 달력으로 관리하고, 회원·게스트와 함께 참여 인원을 정리한다.

컬러 팔레트

#3fdf84 메인 컬러
#00a49d 서브
#2f4858 서브
#ffffff 화이트
#000000 블랙

사이트 기능

달력 보기

  • 월 / 주 / 일 단위 전환

회원 기능

  • 회원가입
  • 로그인
  • 가입한 회원 관리 페이지

일정 등록

  • 각 일자에 시간별 데이터 등록
  • 시작~종료 날짜 및 시간 선택 (datetime)

일정 데이터 항목

테니스장위치주차여부인원수레벨예약자금액메모

참여자 (회원)

인원 n명을 지정할 수 있으며, 참여자는 회원가입한 사용자의 데이터로 추가한다.

참여자 (게스트)

n명 중 '게스트'라는 이름의 데이터도 추가할 수 있다.

세부 메뉴 계획

메인페이지

Tennis.Date 로고로 만든 index페이지 추가 (로고와 한 줄 소개만 두고 대메뉴로 이동)

대메뉴

일정달력, 일정등록, 회원관리

세부메뉴

  • 일정달력 → 세부메뉴 없음
  • 일정등록 → 세부메뉴 없음
  • 회원관리 → 내정보, 전체관리

해당 사이트 우측 상단

한국시간기준 시계(YYMMdd hh:mm:ss 24h), 로그인버튼, 회원가입버튼

페르소나

기본정보

테니스를 시작한 지 얼마 안됐는데 지인들과 치기 위해 일정을 확인해야하는 동호인

사용환경

언제 어느때든 pc나 모바일로 테니스 치기위한 일정 확인을 위해 사이트 방문

목표

본인의 일정을 설정하여 사람을 구하거나, 남의 일정에 참여 신청을 할 수 있어야함

사용자 시나리오

처음 들어온 회원의 회원가입하기

  1. 회원가입 버튼 클릭
  2. 회원가입 화면으로 전환
  3. 아이디, 비번, 이름, 나이, 구력, NTRP 입력 및 아이디, 이름 중복체크
  4. 회원가입 완료 버튼 클릭
  5. 메인 화면으로 전환

로그인

  1. 로그인 버튼 클릭
  2. 로그인 화면으로 전환
  3. 회원가입 시 작성했던 아이디, 비번을 작성하여 로그인 버튼 클릭
  4. 로그인완료 alert(message) 띄운 후 메인 화면으로 전환

일정 확인 및 등록

  1. 대메뉴 에서 "달력" 클릭
  2. 날짜들 중 하루를 클릭하여 해당 날짜에 있는 일정 확인 (비회원은 로그인 안내)
  3. 일정 상세에서 [참여하기] 클릭 시 선착순으로 즉시 참여자에 추가, 정원이 차면 [마감]으로 변경

참여 취소 및 대참자 구하기

  1. 참여 중인 일정에서 [참여 취소] 클릭
  2. 일정 시작 1시간 전까지만 취소 가능, 이후에는 버튼 비활성화
  3. 당일 취소는 취소자가 직접 대참자(회원 검색 또는 게스트 이름)를 지정해야 취소 완료
  4. 대참자를 구하지 못하면 취소되지 않고 참여자로 남음

세부 정책

접근 권한

  • 비회원: 달력에서 일정 유무만 열람, 일정 클릭 시 로그인 필요
  • 회원: 일정 상세 열람, 참여, 일정 등록
  • 운영자: 회원관리 → 전체관리 메뉴 이용 (일반 회원은 내정보만)

참여 방식

선착순 즉시 확정 (승인 절차 없음)

일정 수정/삭제

  • 참여자가 있으면 메모, 금액, 위치 같은 부가 정보만 등록자가 수정 가능
  • 시간, 날짜, 정원은 수정 불가
  • 삭제는 등록자가 요청하면 운영자가 처리

필수 입력

날짜와 시간, 테니스장, 위치, 주차여부, 인원수, 레벨, 예약자, 금액(대관료·캔볼비)은 필수, 메모만 선택

지난 일정

달력에 그대로 남고 상세 열람 가능. 참여·취소·대참 버튼은 비활성화하고 "종료된 일정"으로 표시

예약자

코트를 실제로 예약한 사람. 등록자와 다를 수 있으며 회원 선택 또는 직접 입력

금액

대관료, 캔볼비를 각각 입력하고 합산하여 1인당 금액을 자동 계산해 표시 (회원+게스트 총 인원 기준)

레벨

참고용 표시 (예: NTRP 2.0~3.0), 범위 밖이어도 참여 제한 없음

게스트

일정 등록자만 추가하며, 정원과 1인당 금액 계산에 포함

달력 표시

날짜 칸에 시간과 테니스장 이름 표시, 마감은 회색, 대참 구함은 강조색 (잔여 인원은 표시하지 않음)

모바일 달력

월 보기를 유지하되 칸에는 점이나 색만 표시, 날짜를 누르면 시간·코트명이 있는 목록이 펼쳐짐

운영자

member 테이블에 auth 컬럼을 추가하여 구분 (상세 권한은 추후 정의)

데이터 저장

Supabase 같은 호스팅형 백엔드로 로그인과 DB 처리 (서비스는 개발 단계에서 확정)

제외 범위

  • 알림
  • 비밀번호 찾기
  • 회원 탈퇴
