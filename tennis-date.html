Guide

How to use

가입부터 대참자 구하기까지, 이용 방법을 안내해요.

회원가입

  1. 회원가입 버튼 클릭
  2. 아이디·비번·이름·나이·구력·NTRP 입력 및 중복체크
  3. 가입 완료

로그인

  1. 로그인 버튼 클릭
  2. 아이디·비번 입력
  3. 로그인 완료

일정 확인 및 등록

  1. 대메뉴에서 달력 클릭
  2. 날짜를 눌러 일정 확인 (비회원은 로그인 안내)
  3. [참여하기] 선착순 추가, 정원이 차면 [마감]

참여 취소·대참자

  1. 일정 시작 1시간 전까지 취소 가능
  2. 당일 취소는 대참자(회원 검색/게스트 이름) 지정 필수
  3. 대참자를 못 구하면 참여자로 유지
Policy

Club rules

참여 방식

선착순 즉시 확정 (승인 절차 없음)

일정 수정/삭제

참여자가 있으면 메모·금액·위치만 수정 가능. 시간·날짜·정원은 수정 불가, 삭제는 운영자가 처리.

필수 입력

날짜·시간, 테니스장, 위치, 주차여부, 인원수, 레벨, 예약자, 금액(대관료·캔볼비). 메모만 선택.

금액

대관료와 캔볼비를 합산해 회원+게스트 총 인원 기준 1인당 금액을 자동 계산.

지난 일정

달력에 남고 상세 열람 가능. 참여·취소·대참 버튼은 비활성화하고 “종료된 일정” 표시.

게스트

일정 등록자만 추가하며 정원과 1인당 금액 계산에 포함.
